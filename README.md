# チラシ配布ルート(岐阜市・岐南町)

事務作業の多い事業所を業種で選び、現在地や出発地点から効率よく回る順番を作って、Googleマップでナビするスマホ用ページです。

- 公開アドレス: https://smalldx.github.io/chirashi-route/
- 構成: `index.html` 1ファイル(ビルド不要)
- 地図・住所検索: 国土地理院 / 地図表示: Leaflet / 並べ替え: SortableJS

## 主な機能
- 出発地点:現在地・住所検索・よく使う場所・地図タップ
- 業種(30種類)・距離・今回配る件数・移動手段を選んで、回る順番を自動で作成
- Googleマップでナビ(未配布の次の9件ずつ)
- 配布済み / スキップ / ドラッグで並べ替え / 近くの先を追加 / 現地で新規登録
- 配布済みは日付ごとに別ページで確認、記録のコピーと読み込み

開発メモは `CLAUDE.md` を参照。

配布先は233件(岐阜市111件・岐南町122件)。岐阜市の追加15業種は各2件ずつ登録しています。2026年11月8日に確認した追加データの出典は [DATA_SOURCES.md](DATA_SOURCES.md) を参照。
